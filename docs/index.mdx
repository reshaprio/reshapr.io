## Operate the current baseline

The current product baseline is reShapr **1.1.0**, controllers **0.0.4**, and Helm charts **0.0.15**. See [runtime environment variables](./references/environment-variables.md) for deployment limits and [troubleshooting](./how-to-guides/operations/troubleshoot.md) for diagnostics, including temporary DEBUG logging.
